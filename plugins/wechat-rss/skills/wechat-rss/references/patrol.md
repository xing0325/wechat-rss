# 巡检

运行 `node ./wechat-rss.mjs plan`，根据 `today` 判定香港日期及轮次，把 `sources` 作为来源清单。19:50 的定时运行对应 20:30，22:50 对应 23:30。该轮已经到点时，结束定时巡检，让投递任务使用已有内容。人工补查按用户指定日期及范围执行。

## 定位微信

通过本机 Computer Use 的应用窗口清单定位微信进程和已登录主窗口。微信在后台时，使用工具提供的窗口激活动作恢复。出现多个微信窗口时，逐一核对主会话是否可操作。微信被遮挡、移出屏幕或暂时不可见时，刷新窗口列表和画面，恢复主窗口并核对。只有确认主窗口确实停在登录界面时才报告要扫码。锁屏时需要恢复交互桌面。

## 查来源和链接

1. 优先查股海牧羊人、颖姐财经的公众号和视频号。分别检查公众号和视频号。检查奶爸张sir的视频号、关联公众号「奶爸张 sir」、财经小娟娟视频号、半导体行业观察公众号，以及配置中的其它来源。
2. 对公众号，从「通讯录 → 公众号、服务号」或「搜一搜 → 账号 → 公众号」进入准确账号，检查「文章」分栏及聚合页的「余下 N 篇」。点进原文确认标题、作者和发布时间，使用微信菜单「复制链接」。颖姐财经通过微信「搜一搜 → 账号 → 公众号」，核对北京丰台、女性头像和「天机」主力交易模型简介及署名。注意聚合页可能漏掉公众号的文章。
3. 对视频号，从「发现 → 视频号 → 搜索」进入账号作品页，也可使用微信侧栏的搜索或浏览器入口。按配置核对认证、地区、简介及关联账号。进入作品后用原生分享菜单复制该条作品链接。通过作者附近的日期、封面文案、时长等确认标题与作品标识。排除旧置顶和直播预告。
4. 每条视频核验完立即暂停，再切到下一条。退出前确认最后一个播放器显示播放三角按钮。无法确认暂停时，只关闭本轮打开的播放标签，并检查播放已停止。
5. 沿时间顺序查到已知非置顶作品或可确认的日期边界后，才记录 `complete`。确认作品列表只有直播提示、加载失败、识别或覆盖不足时填 `partial` 和原因。颖姐财经视频号只显示直播预告时，仍需查同名公众号。只记录有证据的标题、作者和链接，不从正文拼造链接。缺链接的已确认作品可以入库，补链接时保持同一标识。

## 入库

每个来源写一份 UTF-8 JSON，按新到旧排列，先在项目 `state` 下存成独立文件。标题和定位线索必填。公众号文章可用微信短链接或完整文章链接生成标识。同一作品已在 `plan` 的 `recentItems` 时复用原 `identity`。视频等不能自动生成标识的条目，采用能复核且稳定的作品文字、时长和日期组合。作品未给出单独署名时可以省略 `author`，汇总会使用发布账号名。

```json
{
  "sourceId": "video-guhaimuyangren",
  "coverage": "complete",
  "items": [
    {
      "title": "示例作品",
      "author": "股海牧羊人",
      "identity": "示例封面文案｜06:18｜2026-11-23",
      "locator": "创作者主页，示例封面文案，时长 06:18"
    }
  ]
}
```

有实际复制的微信链接时填入 `url`。巡检部分覆盖时填 `coverage: "partial"` 与 `note`，并保留已核实条目的数据。每份运行 `node ./wechat-rss.mjs ingest --input ./state/<文件名>.json`。

首次巡检用确认的旧作品建立基线，旧内容留在基线。已核实当日新作时把旧作先单独入库，再提交当日新作。若确认扫到当天 00:00 边界但无可用旧作，可先为该来源提交空的 `complete` 建基线，再单独提交当日新作。还没覆盖到基线时只记录 `partial`，暂存已见条目线索，等再次核验后入库。已在待发队列里的漏收条目继续保留。

## 备稿和临近复查

- 首轮从 20:00 起运行 `node ./wechat-rss.mjs prepare --round 20:30`。晚轮从 23:00 起运行 `node ./wechat-rss.mjs prepare --round 23:30`。
- 约 20:25 复查两个必看号。约 23:25 优先复查首轮无推送条目的必看号，避免过早认定未更新。在到点前入库复查结果，准备过的稿件用 `prepare --round <HH:mm> --refresh` 更新。
- 执行 `digest --round <HH:mm>` 复核已备稿。到点结束巡检，给投递任务留下前台。
- 人工核对近十天发布时间时，从香港日期与微信明示时间统计每个账号的实际样本。分别看公众号与视频号，缺失的具体时分保留未知。此操作无须把历史内容送入待发队列。
